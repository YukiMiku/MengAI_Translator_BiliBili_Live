# 萌AIちゃん　v1.4.3

## 主な機能

### 接続

- **配信ルームへの接続** — B 站のルーム ID を入力して「接続」を押すと、コメントサーバー（WebSocket）につながります。**接続した瞬間からのリアルタイムコメントだけ**を取得し、過去のコメントは読みません。**未配信・リピート中でも接続できます**。

- **状態表示** — 接続状態（未接続 / 未配信 / 配信中 / リピート中）、人気値、翻訳キュー、接続中の監視クライアント数を画面上部に常時表示します。

- **B 站ログイン（任意）** — `SESSDATA` を 1 行用意し、「cookie ファイルを開く」に貼って「読み込んで確認」を押すだけです。`bili_jct` / `DedeUserID` は不要（uid は自動取得）。**未ログインだとユーザー名が「頭文字***」・uid=0 で返ることがあり**、その件数は警告として表示されます。「ログイン情報を消去」でいつでも解除できます。⚠ このファイルはアカウント資格情報そのものなので、他人に渡さないでください。

### 翻訳サービス

- **6 種類から選択** — DeepSeek (API) / DeepSeek Web版 / ChatGPT Web版 / OpenAI (API) / OpenAI 互換 / Ollama。API キー不要の Web 版から、完全ローカルで動く Ollama まで選べます。

- **API 系の設定** — API Base URL・モデル・API キー・システムプロンプトを指定して「設定を保存」。API キーは**空欄にすると既存のキーが維持**されます。保存されたキーは **Windows の DPAPI で暗号化**され、`data/config.json` を開いても平文では読めません（画面上にも「暗号化保存済み / 未保存」が表示されます）。

- **Web 版は追加インストール不要** — お使いの Chrome / Edge を**本プログラム専用のウィンドウ**でそのまま使います。playwright もブラウザカーネルのダウンロードも不要です。DeepSeek はログイン状態が自動で引き継がれ、ChatGPT は暗号化 Cookie のため一度だけログインが必要（以後は記憶）。※ Chrome 136 以降は既定プロファイルでデバッグできないため専用プロファイルを使います。

- **同時翻訳数とキャッシュ** — 並列して翻訳する件数（既定 3）と、翻訳キャッシュの有効／無効を設定できます。

- **日本語コメントは翻訳しない** — 日本語のコメントでは AI を呼ばず原文のまま表示します（翻訳キューにも入りません）ので、無駄な消費がありません。

### 用語集

- **1 行 1 件の書式** — `元の語 => 日本語訳 | ピンイン # 備考` で書きます。決めた語を必ずその訳に固定でき（例：`草 => w`）、行末に `[禁用]` を付けるとその行だけ無効にできます。

- **ピンイン列** — ルビの**上書き専用**です（多音字や固有名詞に有効）。`xiao3` でも `xiǎo` でも書けます。**翻訳には使われません**。

- **編集と管理** — 「用語集ファイルを開く」でメモ帳などの既定プログラムで直接編集、「用語集をインポート」で TXT / CSV / JSON を取り込み、「用語集をエクスポート」で書き出せます。表から「追加」「選択を削除」もできます。

- **複数の用語集** — 「用語集を新規作成」で場面ごとに分けられます。**プリセットが現在の用語集を覚える**ので、プリセットを読み込むと自動的に切り替わります（例：雑談用とゲーム用で訳し分け）。

### プリセット

- **1 件 = 1 ファイル** — 翻訳サービス・API の設定・システムプロンプト・同時翻訳数・キャッシュ・API キー・用語集に加えて、**配色 / 背景画像 / 文字サイズ / ルビ設定 / ギフト設定**までまとめて保存・復元できます。保存先は `data/presets/*.json` で、1 つのプリセットが 1 ファイルです。

- **保存 / 読み込み / 削除** — 名前を付けて「保存プリセット」、一覧から選んで「読み込み」、不要なら「削除」。同名で保存すると上書き確認が出ます。

- **エクスポート / インポート** — 「ファイルへ書き出し」「ファイルから読み込み」で任意の場所とやり取りできます。`data/presets/` フォルダを**まるごとコピー**すれば別の環境へも持って行けます。

- **旧版からの自動移行** — 以前 `config.json` に入っていたプリセットは、初回起動時に自動で個別ファイルへ移行します（**同名ファイルは上書きしません**）。移行件数はログに表示されます。

### 外観

- **ウィンドウ配色** — ホワイト / ブラック / ブルー / ピンクの 4 種類。クリックで即時反映され、そのまま保存されます。

- **コメント欄の背景画像** — 「画像を選択」で設定し、**拡大率・不透明度・水平位置・垂直位置**をスライダーと**数値入力**の両方で調整できます。「初期値に戻す」「コメント欄に合わせる」も用意。背景画像は**スクロールしても固定**され、文字はその上に描画されます。透過 PNG の透明部分はコメント欄の地色が出ます（黒くはなりません）。

- **Pillow の導入 / 修復** — ボタン 1 つで導入できます。入れると JPG / WEBP の背景画像が使え、拡大縮小も滑らかになります（Tk 標準は PNG / GIF のみ）。

- **ピンインルビ** — 中国語コメントの**原文の上に、一文字ずつ**声調つきのピンイン（`zhè shǒu gē` の形）を表示します。日本語・英数字・約物・絵文字には付かないので原文が崩れません。スイッチで ON/OFF できます。

- **文字サイズ** — 原文 / ルビ / 訳文の 3 つを個別に指定できます。値は自動的に「**原文 > ルビ ≥ 訳文**」に調整されます。なおルビを表示すると、1 行に入る漢字は 1/2〜1/3 程度になります。

- **ギフト** — 「無料ギフト（銀瓜子）を除外」スイッチ（既定はオフ）。
