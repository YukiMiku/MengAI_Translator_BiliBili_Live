# 萌AIちゃん
ビリビリ動画の配信ルームのコメントをAIで翻訳できる用語集付きツール、すべてのコードはdeepseekにより生成しました。
Bilibili のコメントをリアルタイムで日本語に翻訳する、Windows 用のデスクトップツールです。
Python のインストールは不要 —— ポータブル版に実行環境を同梱しているので、インストーラーを 1 回実行するだけで使えます。
中文 | 日本語
配信部屋のコメントを取得し、日本語以外のコメントだけを AI で日本語に翻訳して表示します。
OBS のカスタムブラウザドックにも対応しているので、配信中そのまま画面に出せます。
> バージョン **v1.2.0** / Windows 10・11（64 ビット）/ インターフェースは**既定で日本語**（中国語にも切り替え可能）
---
インストール（ポータブル版・推奨）
Python を入れる必要はありません。 次の 2 ステップだけです。
`install.bat` をダウンロードします。
Releases に置いてある場合は、Assets から `install.bat` をクリック
リポジトリ直下にある場合は、`install.bat` を開いて Download raw file をクリック
`install.bat` をダブルクリックします。
インストーラーが自動で次を行います。
Releases からポータブル版をダウンロード（約 16.5 MB）して展開・インストール
インストール先：`%USERPROFILE%\萌AIちゃん`
デスクトップにショートカット（`萌AIちゃん`）を自動作成
Pillow を追加インストールするか確認（JPG / WEBP の背景画像と滑らかな拡大縮小に必要。約 7 MB）
インストール後は、デスクトップのショートカットをダブルクリックするだけで起動できます。
> **アンインストール**：`%USERPROFILE%\萌AIちゃん` フォルダとデスクトップのショートカットを削除するだけです。レジストリは使いません。
>
> **アップグレード**：`install.bat` をもう一度実行するだけです。`data/`（設定・用語集・ログイン情報）は**自動的に保持されます**。
>
> **日本語以外の言語版 Windows をお使いの場合**：インストール先を ASCII のパスにしてください。
> `install.bat -Dest "D:\MengAI"` のように指定できます（理由は後述）。
主な機能
リアルタイム翻訳 — 接続した瞬間からのコメントだけを WebSocket で受け取り、その場で翻訳します（過去のコメントは取得しません）。
未配信でも接続できる — 配信開始を待たずに「接続」を押せます。状態は 未配信 / 配信中 / リピート中 を表示。
日本語コメントは翻訳しない — 日本語のコメントでは AI を呼ばないので、無駄な消費がありません。
6 種類の翻訳サービス — DeepSeek (API) / DeepSeek Web版 / ChatGPT Web版 / OpenAI (API) / OpenAI 互換 / Ollama。
Web 版は追加インストール不要 — お使いの Chrome / Edge をそのまま使います（playwright もブラウザカーネルのダウンロードも不要）。
ローカル用語集 — `元の語 => 日本語訳` の 1 行形式。TXT / CSV / JSON のインポート、複数の用語集の切り替えに対応。
プリセット — 翻訳サービス・プロンプト・同時翻訳数・用語集・配色・背景画像をまとめて保存／復元。場面ごとに訳し分けられます。
4 種類の配色 + コメント欄の背景画像 — ホワイト / ブラック / ブルー / ピンク。背景画像は拡大率・不透明度・位置をスライダーと数値入力で調整できます。
B 站ログイン（任意） — `SESSDATA` をファイルに 1 行書くだけで、ユーザー名が `頭文字***` になる「伏せ字」を解消できます。
OBS ドック — `http://127.0.0.1:17890/dock` をブラウザドックに貼るだけ。
起動時に README を表示 — 説明ウィンドウが開き、右上で 日本語 / 中文 を切り替えられます。
API キーは DPAPI で暗号化 — `data/config.json` に平文で保存されません。

Web 版のポイント
本プログラム専用のブラウザウィンドウを使います（お使いの Chrome / Edge を再利用。追加インストールは不要）。
初回は普段使っているブラウザのログイン情報の取り込みを試みます。DeepSeek はそのままログイン済みになります。
ChatGPT は暗号化 Cookie のため移行できず、専用ウィンドウで一度だけログインが必要です（以後は記憶されます）。
ログイン情報は `data/browser_profile` に保存されます。やり直したいときはこのフォルダを削除してください。
先に Web 側で「深度思考」と「联网搜索」をオフにしておくことをおすすめします（数倍速くなります）。
OBS ドック
OBS → 表示 → ドック → カスタムブラウザドック
URL に `http://127.0.0.1:17890/dock` を貼り付け
（プログラム内の「ドックURLをコピー」を使うと確実です）
表示専用で、ドックから操作することはできません。
用語集ファイル
`data/glossary.txt` に 1 行 1 件で書きます。
```
元の語 => 日本語訳 # 備考
```
```
草 => w # 笑いを表す
可爱 => かわいい
```
備考として認識されるのは `#` だけです（訳文末尾の「（…）」は訳文の一部として扱われます）。
行末に `[禁用]` を付けるとその項目を無効にできます。
「用語集を新規作成」で複数の用語集を作り、プリセットと紐づけて場面ごとに訳し分けられます。
インストール先について
インストール先は `%USERPROFILE%\萌AIちゃん`、ショートカットは `萌AIちゃん` です。
日本語版 Windows（ANSI コードページ 932）では Shift-JIS で表現できる文字だけなので、そのままで問題ありません。
日本語以外の言語版 Windows をお使いの場合は、`install.bat -Dest "D:\MengAI"` のように ASCII のパスを指定してください。
Windows のシェル（`WScript.Shell`）は ANSI コードページでパスを扱うため、そこで表現できない文字が入ると
ショートカットの作成に失敗します（しかもエラーを出さず、成功したように見えます）。
なお、実際に実行するファイル名（`launch.bat` / `check.bat` / `debug.bat`）はすべて ASCII です。
困ったときは
まず `check.bat` をダブルクリックしてください。
Python のバージョン、`tkinter`、必要なファイル、ポート、フォルダの権限を 1 項目ずつチェックして結果を表示します。
そのほか、`python app.py --selftest`（起動可否だけを検証）や、プログラムのフォルダに出力される `启动错误.txt`（完全なスタックトレース）も使えます。
