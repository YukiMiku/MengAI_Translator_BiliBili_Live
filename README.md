# 萌AIちゃん v1.4.11

B 站（ビリビリ）のコメントを**リアルタイムで日本語に翻訳**する、Windows 用のデスクトップアプリです。
中国語コメントに**ピンインルビ**を付け、ギフト・入場・艦長・スーパーチャットも同じ画面にまとめて表示します。
中文名は **AI萌译酱**。UI は日本語と中国語を切り替えられます。

## 動作環境

- Windows 10 / 11（64 ビット）
- **Python のインストールは不要** — 同梱の Python 3.14.7 ランタイムで動きます

## インストール

1. **リポジトリ直下の `install.bat` をダウンロード**し（右クリック →「名前を付けて保存」）、**純 ASCII のパス**（例：`D:\MengAI\`）に置きます。
2. **`install.bat` をダブルクリック**します。GitHub Releases から本体をダウンロードし、**`install.bat` と同じフォルダの下の `萌AIちゃん`** にインストールして、**デスクトップにショートカットを自動作成**します（Pillow を追加するかも尋ねられます。任意です）。
3. **デスクトップのショートカットをダブルクリック**して起動し、上部のルーム ID 欄に B 站のルーム ID を入れて「接続」を押します。

- **アップグレード** — もう一度 `install.bat` を実行するだけです（上書きインストール。`data/` は保持されます）。
- **インストール先の変更** — `install.bat -Dest "D:\MengAI"` のように `-Dest` で指定できます。
- **日本語以外の言語版 Windows** — パスに表現できない文字があるとショートカットが作れないことがあります。その場合は `-Dest` で純 ASCII のパスを指定してください。

## 接続

**配信ルームへの接続** — B 站のルーム ID を入力して「接続」を押すと、コメントサーバー（WebSocket）につながります。接続した瞬間からの**リアルタイムコメントだけ**を取得し、過去のコメントは読みません。未配信・リピート中でも接続できます。

**状態表示** — 接続状態（未接続 / 未配信 / 配信中 / リピート中）、人気値、翻訳キュー、監視クライアント数を画面上部に常時表示します。

**B 站ログイン（任意）** — SESSDATA を 1 行用意し、「cookie ファイルを開く」に貼って「読み込んで確認」を押すだけ。bili_jct / DedeUserID は不要です（uid は自動取得）。未ログインだとユーザー名が伏せ字（頭文字＋アスタリスク 3 つ）で返ることがあり、その件数は警告として表示されます。⚠ SESSDATA はアカウント資格情報そのものです。他人に渡さないでください。

## 翻訳サービス

**6 種類から選択** — DeepSeek (API) / DeepSeek Web版 / ChatGPT Web版 / OpenAI (API) / OpenAI 互換 / Ollama。API キー不要の Web 版から、完全ローカルで動く Ollama まで選べます。

**API 系の設定** — API Base URL・モデル・API キー・システムプロンプトを指定して「設定を保存」。API キーは **Windows の DPAPI で暗号化**して保存され、`data/config.json` を開いても平文では読めません。

**Web 版は追加インストール不要** — お使いの Chrome / Edge を専用ウィンドウでそのまま使います。playwright もブラウザカーネルのダウンロードも不要です。

**同時翻訳数とキャッシュ** — 並列して翻訳する件数（既定 3）と、翻訳キャッシュの有効／無効を設定できます。

**日本語コメントは翻訳しない** — 日本語のコメントでは AI を呼ばず原文のまま表示します（翻訳キューにも入りません）。

## コメント欄

**ピンインルビ** — 中国語コメントの原文の上に、一文字ずつ声調つきのピンイン（`zhè shǒu gē` の形）を表示します。日本語・英数字・約物・絵文字には付かないので原文が崩れません。スイッチで ON/OFF できます。

**文字サイズ** — 原文・ルビ・訳文・ユーザー ID を個別に指定できます。値は自動的に「**原文 > 旧 ID > 新 ID = ルビ = 訳文**」の階層に調整されます。

**表示の色分け** — 訳文は青、翻訳待ちは橙、エラーは赤。原文のすぐ下に訳文が出ます。

**まとめて消去** — ボタン 1 つでコメント・ギフト・入場の記録をまとめて消せます。

## ギフト・入場・艦長 / SC

**ギフト欄** — ギフト名・個数・価格を記録します。**連撃は最終的な個数だけ**を表示し、同じ人が別のタイミングで送った同じギフトは別の行になります。件数の上限はありません。

**入場通知** — 入場したユーザーの ID と、その ID のピンインを表示します。

**艦長 / スーパーチャット（SC）** — 艦長・提督・総督の区別と、SC の金額・本文を表示します（本文にもルビが付きます）。

**ギフトの精度** — ギフト名を取得できなかった記録は**行を作りません**（何のギフトか分からない表示を出さないため）。

## 用語集

**1 行 1 件の書式** — `元の語 => 日本語訳 | ピンイン # 備考`。決めた語を必ずその訳に固定でき（例：`草 => w`）、行末に `[禁用]` を付けるとその行だけ無効にできます。

**ピンイン列** — ルビの上書き専用です（多音字や固有名詞に有効）。`xiao3` でも `xiǎo` でも書けます。翻訳には使われません。

**編集と管理** — 「用語集ファイルを開く」で既定のエディタで直接編集、「インポート」で TXT / CSV / JSON を取り込み、「エクスポート」で書き出せます。

**複数の用語集** — 場面ごとに分けられます（例：雑談用とゲーム用）。プリセットが現在の用語集を覚えるので、読み込むと自動で切り替わります。

## プリセット

**1 件 = 1 ファイル** — 翻訳サービス・API 設定・システムプロンプト・同時翻訳数・キャッシュ・API キー・**B 站ログイン情報（SESSDATA）**・用語集・配色・背景画像・文字サイズ・ルビ設定・ギフト設定まで、まとめて保存・復元できます（`data/presets/` 以下の JSON）。

**保存 / 読み込み / 削除** — 名前を付けて保存、一覧から選んで読み込み、不要なら削除。同名で保存すると上書き確認が出ます。

**エクスポート / インポート** — 任意の場所とやり取りでき、`data/presets/` をまるごとコピーすれば別の環境へも持って行けます。

## 外観

**ウィンドウ配色** — クリーム / ブラック / スカイブルー / ピンクの 4 種類。クリックで即時反映され、そのまま保存されます。**スライダーの配色もテーマごとに追従**して見やすくしてあります。

**コメント欄の背景画像** — 拡大率・不透明度・水平位置・垂直位置を、スライダーと数値入力の両方で調整できます。透過 PNG の透明部分はコメント欄の地色が出ます（黒くはなりません）。

**Pillow の導入 / 修復** — ボタン 1 つで導入できます。入れると JPG / WEBP の背景画像が使え、拡大縮小も滑らかになります（Tk 標準は PNG / GIF のみ）。

## 記録

**ローカルログ** — その回の記録を `data/logs/` にファイルとして残します。OBS 用のドックページも同じ内容を表示します。
